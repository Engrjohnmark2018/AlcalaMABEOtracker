# Project Documentation & Reference Samples

This folder contains user guides, reference templates, and sample exports for the **ABE Office — Alcala Work & Accomplishment Tracker**.

## Contents

- **`Setup Guide.docx`** — Office workstation setup, configuration instructions, and operational walkthrough.
- **`Sample-Travel-Order-Template.docx`** — Working sample Word document template showcasing placeholders (`{{CreationDate}}`, `{{Purpose}}`, `{{TravelDate}}`, `{{Destination}}`).
- **`Sample-Weekly-Schedule.pdf`** — Sample generated Monday–Friday weekly schedule exported as PDF.
- **`Sample-Weekly-Schedule.png`** — Sample 2× resolution weekly schedule exported as PNG.
