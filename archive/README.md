# Historical & Legacy Archive

This directory stores historical files, original scripts, and reference workbooks preserved during the Vite + Vue 3 refactoring and TEV automation integration.

## Archive Contents

- **`legacy-index.html`** — The original 5,600+ line monolithic single-file application. Retained for historical reference and parity auditing.
- **`GScript/`** — The original Google Apps Script project (`code.gs`, `DataEntry.html`) formerly used for Google Sheets and Drive batch processing.
- **`Generated TO, IOT, COE, CTC/`** — 40 historical batch output folders generated during the legacy Google Drive/Sheets workflow.
- **`Templates/`** — Original raw Excel and Word templates. The active application templates are bundled and served from `public/templates/`.
- **`reference-files/`**:
  - `TEV Automation - Template.xlsx` — Baseline spreadsheet with formulas and layout.
  - `TEV Automation.xlsx` — Reference workbook containing sample travel data and fare matrix.
  - `Travel Order - Template Files.zip` — Historical compressed archive of template files.
